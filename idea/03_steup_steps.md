# Environment Setup — AI Circuit Optimizer

## 1. System Requirements

- Python 3.11+
- Node.js 18+
- C++17 compatible compiler (g++ / clang)
- CMake ≥ 3.4
- Git + GitHub account
- (Optional) Logisim Evolution

---

## 2. Python Environment

```bash
# Create and activate virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install fastapi uvicorn opencv-python sympy torch networkx matplotlib pybind11 python-multipart jinja2 requests
```
